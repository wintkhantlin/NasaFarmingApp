## Acceptance rules

- **Daily temperature:** good if |bias| ≤ 1 °C and RMSE ≤ 2 °C; usable if ≤ 2 °C and ≤ 3.5 °C.
- **Monthly rain totals:** good if |relative bias| ≤ 15% and r ≥ 0.85; usable if ≤ 30% and r ≥ 0.7. A month counts only with station readings on ≥ 90% of its days.
- **Limit days (heat, cold):** good if POWER catches ≥ 70% of observed days with ≤ 30% false alarms; usable at ≥ 50% and ≤ 50%. Needs ≥ 20 observed days.
- These are this project's rules for screening-level use, chosen before the results were seen. They are not an international standard.
